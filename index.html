PowerShell Commands

Run commands in your basketball_first_half folder. Copy only — this dashboard cannot run commands on your computer.

Daily

Refresh today

Fetch today’s fixtures, refresh predictions and settle completed games.

python daily.py refresh
Refresh tomorrow

Save tomorrow’s pre-game forecasts ahead of tipoff.

python daily.py refresh --date (Get-Date).AddDays(1).ToString("yyyy-MM-dd")
Refresh chosen date

Replace the example date with your chosen YYYY-MM-DD.

python daily.py refresh --date 2026-10-18

Live

Start live watch

Poll roughly every three minutes; leave PowerShell open, Ctrl+C to stop.

python daily.py watch --interval 180
Watch with verified scores

Only if you have entered verified elapsed time and cumulative points.

python daily.py watch --interval 180 --live-input live_scores.json

Results

Open dashboard

Open the saved dashboard; refresh your browser after the command runs.

start reports/dashboard.html
Backtest summary

Show historical pre-match forecast accuracy.

python engine.py backtest-summary
V14 market validation

Rebuild chronological match and team-total validation report.

python validate_v14.py
Open V14 validation dashboard

Open league holdout comparisons and market-line experiments.

start reports/v14_validation.html
Data status

List imported games by league.

python engine.py data-status

Data

Import major leagues

Fetch historical games across configured leagues; uses API quota.

python import_major_leagues.py --delay 2
Run tests

Check that the prediction project still passes its tests.

python -m unittest discover -s tests
